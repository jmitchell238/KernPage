# Third-party notices

KernPage is dual-licensed under MIT or Apache-2.0 (see `LICENSE-MIT`, `LICENSE-APACHE`). It uses the
open-source components below. The installer ships this file and `THIRD_PARTY_LICENSES.html`
(generated by `cargo about`, see `about.toml` and `about.hbs`) in the install folder.

## Rust dependencies

`THIRD_PARTY_LICENSES.html` lists every Rust crate that is built into the Windows programs, with its
licence text. Regenerate it with `cargo about generate about.hbs -o THIRD_PARTY_LICENSES.html`
(`packaging/windows/package.ps1` does this for every installer build).

## Fonts

`egui`/`eframe` (MIT or Apache-2.0) bundle these default fonts as fallbacks for text that no
installed system font covers:

- Hack (MIT-style licence, Source Foundry)
- Ubuntu-Light (Ubuntu Font Licence 1.0)
- NotoEmoji-Regular and emoji-icon-font (SIL Open Font License 1.1)

Their licence texts are in `THIRD_PARTY_LICENSES.html`. KernPage bundles no other fonts. Document text
is drawn with the TrueType fonts installed on the user's computer; no Microsoft font files are shipped.

## Icons

Toolbar icons come from Kernicons, the project's own icon set (MIT OR Apache-2.0). The application icon is an
original drawing by the project: a K whose stem is a rolled spine and whose arms are pages (see `packaging/windows/icon/`).

## Installer (WiX Toolset)

The installer is built with the WiX Toolset (MS-RL). `packaging/windows/bundle-theme.xml` and
`bundle-theme.wxl` are derived from the WiX standard bootstrapper theme (Copyright (c) .NET Foundation
and contributors, Microsoft Reciprocal License). Those two files stay under the MS-RL; the source files
are in this repository and the licence text is in `LICENSES/MS-RL.txt`, which the installer also ships.
