# Brand usage checklist

Every place the KernPage **wordmark** (the word "KernPage" with the capital P built from the K) and the **icon** (the K
mark, the tiled app icon, the `.ico` files, installer art, favicon) is used. When the artwork changes, go down both
tables and update each row. The artwork itself is described in [brand/README.md](../brand/README.md).

How rows get their artwork:

- **generated**: written by `brand/make_brand.py` (run `C:\Python312\python.exe -I brand/make_brand.py` from the repo root;
  it needs cargo and the sibling `kernicons` repo for the PNGs).
- **embedded**: compiled into a program with `include_str!` / `include_bytes!`, so rebuild after changing the file.
- **by hand**: copied or set manually.

## Wordmark

| Where | Artwork / variant | How it gets there | How to update |
| --- | --- | --- | --- |
| `brand/kernpage-wordmark.svg` | Recolourable master (CSS variables) | generated; the geometry lives in `WORDMARK_BODY` in `brand/make_brand.py` | Edit `WORDMARK_BODY` / `WORDMARK_VIEWBOX` in the script, rebuild |
| `brand/<accent>/kernpage-wordmark-light.svg` / `.png` and `-dark.svg` / `.png` (teal, blue, purple, graphite, orange) | Static files, 1200 px wide PNG | generated | Rebuild with `make_brand.py` |
| `packaging/windows/icon/kernpage-wordmark.svg`, `kernpage-wordmark-white.svg` | Teal, light and dark approved copies | generated (`approved_wordmark`); the script's self-check compares them with the masters | Rebuild with `make_brand.py` |
| `README.md` header (lines 3-4) | `brand/teal/kernpage-wordmark-dark.png` and `-light.png`, 420 px wide | by hand (path reference to generated files) | Nothing, unless the file names change; check the width still looks right |
| `crates/kernpage/src/logo.rs` (`svg()` and `aspect()`) | `brand/<accent>/kernpage-wordmark-{light,dark}.svg`, drawn at the current accent and theme | embedded (`include_str!`) | Rebuild after `make_brand.py`; update the width / height constant in `aspect(Mark::Wordmark)` if the viewBox changes (now 1249.19 / 329.5) |
| `crates/kernpage/src/backstage.rs`: File > Home page header (`home_page`) and File > About page (`about_page`) | Wordmark, 40 pt tall, current accent and light or dark theme | embedded via `logo::show` | Change the height in the two `logo::show` calls |
| `crates/kernpage/src/ui_tests/logo.rs` | Tests for the wordmark colours, accent and theme | by hand | Update only if colours or roles change |
| `brand/README.md`, `packaging/windows/icon/README.md` | Text that describes the wordmark | by hand | Edit the text |
| Installer welcome art `packaging/windows/assets/dialog.bmp`, `banner.bmp` | The text "KernPage" drawn with a system font by `make_art.py`; not the wordmark artwork | generated by `packaging/windows/assets/make_art.py` | Decide whether to draw the new wordmark instead; if so, change `make_art.py` and rerun it |
| Docs screenshots in `docs/images/` | App screenshots; the File > Home and About pages would show the wordmark | by hand (screenshots taken from the app, `--screenshot`) | Retake any that show the File > Home or About page |
| 238apps website repo (238apps-site): KernPage page header / hero, home page app card, og image | Wordmark (light or dark PNG / SVG) | by hand, copied from `brand/<accent>/` | TODO: exact paths |
| GitHub repository social preview | Wordmark on a card, 1280x640 | by hand: repository Settings > Social preview | Upload a new image |
