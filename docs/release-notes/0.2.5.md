## Added
- Master pages: a page in the background that other pages share. Anything on it (a header, a footer, a page number, a logo) shows on every page that uses it, so you set it up once.
  - Open it with View > Master Page or Ctrl+M and edit it like a normal page. The Master Page tab adds, duplicates, renames and deletes master pages, and applies one to the current page, all pages or a range of pages.
  - Page Design > Master Pages (or right-click a page in the Pages pane) chooses which master a page uses, or None to hide it on that page.
- Insert > Header and Footer open the master page with the header or footer ready to type in.
- Insert > Page Number puts a page number at the top or bottom (left, centre or right) of the master page, so every page shows its own number. It can also go into the text box you are typing in.
- Master pages, and new page numbers, are saved in both .pub and .kern files.

## Fixed
- Page numbers in a .pub file with more than one text story could be saved in the wrong place.

## Not yet
- Two-page (left and right) master pages, and master pages with different margins, can't be saved into .pub files yet. KernPage tells you when a save would need them.
