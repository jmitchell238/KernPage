## Added
- First public release of KernPage, a free desktop publishing app for Windows for bulletins, newsletters, flyers and programs. It also opens, edits and saves Microsoft Publisher (.pub) files.
- KernPage's own open file format, `.kern`. New publications save as `.kern`; Save As can also write `.pub`. The format is documented in `docs/spec/KERN-FORMAT.md`.
- `.kern` files open in KernPage when double-clicked and have their own document icon.
- The start screen shows a picture of each recent publication's first page.
- Master pages and page numbers in opened files are shown, printed and kept when saving.
- A Church Bulletin template.
- KernPage Launcher: opens KernPage and recent files, installs signed updates and can go back to an older version.

## Fixed
- Saving keeps page-number fields and page-number sections correct after editing text or adding and deleting pages.
