## Fixed
- Updating KernPage keeps the desktop shortcuts you chose when you first installed it. Before, an update could remove the KernPage Launcher shortcut.
- The ribbon's group boxes now have one sharp border, even spacing on every side, and enough room on the right for the last word in each column. Labels no longer run into each other.
- Buttons that are switched on (for example Normal, Single Page and Whole Page on the View tab) now share one clear "selected" look that stays inside its group.
- Tab names sit in the middle of their highlight.
- The page pictures under New on the File screen have a clean folded corner, including on the Church Bulletin template.

## Changed
- The Recent list shows when you last opened or saved each file ("Opened today 10:24", "Opened yesterday", "Opened 23 Nov 2026"), so the dates always match the order of the list. Files from before this version show their date again after you next open them.
- New KernPage logo: "KernPage" with a capital P that matches the K and has a folded page corner.

## Added
- KernPage includes a backup font (Noto Sans) for its own menus and buttons, used only if a computer is missing Segoe UI. Your publication fonts are not affected.
