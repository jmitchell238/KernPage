## Changed
- One bar at the top of the window: Save, Undo, Redo, the file name and the search box now sit in the window's title bar, with minimise, maximise and close at the top right. Dragging, snapping to the screen edges, the snap-layout picker on the maximise button, resizing and double-click to maximise all work as before.
- New look for the File screen: a KernPage teal menu down the left with the logo at the top, and the File/Home/Insert tab row is hidden while the File screen is open (the back arrow or Esc brings it back).
- Home shows the page sizes to start from (8.5 x 11", 11 x 8.5", and More page sizes at the end) above a full-width Recent list with a small page picture, the folder and when you last opened each file. More templates opens the built-in templates.
- The New and Open pages match the new look, and page pictures are white like paper in the dark theme too.

## Fixed
- The KernPage Launcher's Recent files list showed "Modified Opened today 16:14"; it now shows "Opened today 16:14".
